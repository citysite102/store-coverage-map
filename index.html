資料來源與限制

Uber Eats 服務範圍取自 Uber Eats 公開的北北基服務範圍地圖，資料更新時間為 2025-11-20，邊界經過簡化（約 100 公尺），現況可能已經不同。這個工具與 Uber Eats 無關。

台北市界取自 g0v/twgeojson 的縣市界資料，簡化至約 30 公尺。

所有距離都是直線距離，沒有考慮河流、山路與實際路線。成本試算的結果取決於你填入的假設，僅供估算。

載入地圖前，需要你自己的 Google Maps API Key

這個工具沒有內建 Key，每位使用者用自己的 Key 載入地圖，用量也算在各自的帳戶上。不載入地圖也可以先用座標新增門市倉，左側的分區面積與成本試算照常運作。

1
申請 API Key（約 5 到 10 分鐘）
已經有 Key 可以直接跳到步驟 3。需要準備一個 Google 帳號和一張信用卡，信用卡只用來建立帳單帳戶，用量在免費額度內不會扣款。
A. 建立專案並綁定帳單
  1. 開啟 Google Cloud Console 並登入。
  2. 點最上方的專案選單，按「新增專案」，名稱自訂（例如 coverage-map），按「建立」。
  3. 開啟 帳單頁面，依畫面指示建立帳單帳戶並連結到剛才的專案。
B. 啟用需要的 API
  1. 開啟 Google Maps Platform 的 API 清單，確認上方選的是剛建立的專案。
  2. 找到 Maps JavaScript API，點進去按「啟用」。這是顯示地圖必要的。
  3. 找到 Geocoding API，同樣按「啟用」。只有用到「輸入地址查詢」時才需要。
C. 建立金鑰
  1. 開啟 Google Maps Platform 的憑證頁。
  2. 按「建立憑證」，選「API 金鑰」。
  3. 畫面會顯示一串 AIza 開頭的文字，按複製。之後也可以回到這一頁按「顯示金鑰」再看一次。

Google 會不定期調整後台的按鈕名稱和位置，如果畫面和上面寫的不同，請以 Google 官方的設定教學 為準。公司配發的 Google 帳號有時被管理員限制，無法建立專案或綁定帳單，遇到這種情況請洽 IT。

2
設定用量保護（建議）
  1. 在憑證頁點進剛建立的金鑰。「API 限制」選「限制金鑰」，只勾 Maps JavaScript API 和 Geocoding API。
  2. 應用程式限制：選「無」。這份檔案是直接從電腦開啟，設了網站限制的 Key 會被拒絕。
  3. 在 配額頁 把這兩個 API 的每日上限設成幾百次，超過就停用，不會產生費用。
3
貼上 Key

Key 只會存在你這台電腦的瀏覽器裡，不會上傳到這個網站，也不會出現在網址上，其他使用者拿不到你的 Key。沒有勾選記住時，關閉分頁就會清除。
