# 門市倉覆蓋範圍

在 Google 地圖上標出門市倉的位置與服務半徑，檢視台北市的覆蓋分區，並試算不同開放範圍的配送成本。

線上版：https://citysite102.github.io/store-coverage-map/

## 使用方式

1. 開啟頁面，依畫面說明貼上自己的 Google Maps API Key（需啟用 Maps JavaScript API；用地址新增或查詢時另需 Geocoding API）。
2. 在「門市倉」分頁新增據點：輸入地址、輸入座標，或在地圖上點選。也可以一次貼上多個。
3. 選擇評估區域（台北市、新北市永和區、新北市新店區），調整服務半徑，檢視三個分區的比例。永和區與新店區內建各里人口，可以在「人口分布」分頁看各分區人口、依距離分段的人口，以及沒有完整落在標準區的里。
4. 在「成本試算」分頁填入各倉的每日單量與配送費率（1 公里內基礎費、第 2 到 3 公里每公里、超過 3 公里每公里），比較三種開放範圍的單均運費、每日運費與外送工時。

沒有 API Key 也可以用座標新增門市倉，分區比例與成本試算照常運作，只是看不到地圖。

## 資料存放

API Key、門市倉清單與成本試算的設定都只存在使用者自己的瀏覽器（localStorage），不會上傳到任何伺服器。這個專案是單一靜態 HTML 檔，沒有後端。

## 分區定義

- 標準區：Uber Eats 有服務，且在服務半徑內
- 延伸區：Uber Eats 有服務，但超過服務半徑
- 山區：Uber Eats 不服務

## 資料來源與限制

- Uber Eats 服務範圍：取自 Uber Eats 公開的北北基服務範圍地圖，資料更新時間 2025-11-20，邊界已簡化。本工具與 Uber Eats 無關。
- 永和區、新店區的里界與人口：[kiang/taiwan_basecode](https://github.com/kiang/taiwan_basecode)（2026-04-07 版村里界，已簡化）與 [kiang/tw_population](https://github.com/kiang/tw_population)（2026 年 10 月各村里人口）。人口只統計到里，里內的分布是推估。
- 台北市界：[g0v/twgeojson](https://github.com/g0v/twgeojson) 縣市界資料，已簡化。
- 所有距離皆為直線距離，未考慮河流、山路與實際路線。
- 成本試算目前只支援台北市。
- 成本試算的預設值為示範用的假設，不代表任何實際費率或單量。
